Концепция: [docs/GATE-ROUTER-CONCEPT.md](docs/GATE-ROUTER-CONCEPT.md).
Реализация ведётся по [тикетам](https://github.com/soltyy/atlas-gate/issues).
Связанный проект: [Atlas Router](https://github.com/soltyy/atlas-router).

Первый этап самостоятельной службы подготовлен в ветке codex/standalone-gate.
