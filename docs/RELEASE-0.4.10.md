# Gate 0.4.10 — крупные оригиналы в коннекторе

Gate #68, Router #75, EDT #215. `/files` сохраняет оригинал на Router для
atlas_file, а не отправляет целиком в модель. Router 0.8.6 разделяет этот
путь с inline PDF/изображениями и снимает ошибочный предел15МиБ.

Gate сохраняет тело исходящей файловой команды отдельным приватным файлом
рядом с БД (`<gate.db>.node-payloads`). SQLite содержит небольшую ссылку,
headers/params и состояния; опросы lease/контекста не перечитывают десятки
мегабайт base64. Poll возвращает прежний wire-конверт Connector.

Тело сохраняется до очереди атомарно, переживает перезапуск Channel,
передаётся только назначенному узлу и удаляется после подтверждения.
Неподтверждённые тела сохраняются для сверки; устаревшие удаляются вместе
с истёкшими записями очереди. Сохраняются ownership, request ID и квитанции.
Для POST /files общие BODY_LIMIT/лимит размера SQLite-очереди не применяются;
новый Connector Router0.8.6 также не применяет общий BODY_LIMIT к оригиналу.

При поставке каталог временных тел включать в приватную резервную копию
Gate рядом с БД. Профили, SDK-история, медиа и существующие квитанции не
переписываются. Прежние изменения сжатия/восстановления и контракта #65
входят в базу этого выпуска.

Проверки и фактическая поставка фиксируются в #68.
