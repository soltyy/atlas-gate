# Gate 0.4.5 — подтверждённый исход создания для Harness

Дополнение #52 для совместной приёмки Harness #304.

## Дополнение контракта подтверждённого отказа

Ответ создания с сохранённым отрицательным исходом содержит
`X-Atlas-Create-Outcome: rejected` и `X-Atlas-Create-Key`, равный исходному
`Idempotency-Key`. Признак выдаётся только при совпадении владельца, организации,
ключа и сохранённых status/body. JSON-обёртка и статус остаются совместимыми.
Ответы без durable receipt, исключения, unknown и конфликт ключа такого
признака не получают. Сам по себе HTTP 502 не доказывает безопасную новую попытку.
Клиент принимает подтверждение только для своего ключа; повторное открытие
сохраняет прежний resume id и не повторяет prompt или результаты инструментов.

Проверки: 14 целевых тестов, в том числе настоящий TCP Gate → Router 0.8.3,
потеря ACK, restart Gate и прежняя история без prompt/tools. Полный прогон: 138 PASS, 6 opt-in SKIP. Установленный сервер ещё не обновлён.
