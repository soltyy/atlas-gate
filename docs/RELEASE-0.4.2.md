# Atlas Gate 0.4.2: абсолютный срок отказа подписки

Gate #48. Исторический RateLimitEvent и cached /v1/node quota больше не продлевают
блокировку при каждом чтении. resetsAt используется как абсолютный Unix timestamp,
без преобразования часового пояса: 21:40 Asia/Bishkek соответствует 18:40 Europe/Moscow.
Относительный fallback применяется один раз к наблюдению; номера событий сохраняются
в SQLite и не позволяют старому allowed/rejected переиграть более новое событие того же хода.
Журнал и cooldown записываются одной транзакцией. Terminal error не сокращает уже известный
абсолютный отказ до fallback60 секунд. Истёкший исторический отказ не создаёт новый cooldown.
Новые реальные события/HTTP-отказы могут начать новый интервал; политики и квоты не отключаются.

Создание сессии при отказе подписки возвращает HTTP429 rate_limit с resetsAt и
retryAfterSeconds, если подходящие Router заблокированы подпиской. Несовместимые модели
и фактические ресурсные ограничения сохраняют прежние проверки; другой свободный аккаунт
может быть выбран для новой сессии. Существующие привязки не переносить между узлами.

Новая таблица router_quota_observations добавляется при старте. Откат исходников допустим:
таблица не удаляет прежние данные. До переключения: SQLite backup API, копия конфигурации,
прежняя ссылка, проверка activeTurns/subagents на обоих Router. Обновляется только Gate.

В production обнаружен исторический cooldown Claude until1792002851.8158467, хотя
подтверждённый SDK reset1791992400 уже истёк. Для этой установки выполнить узкую коррекцию
только при совпадении account_group и прежнего until, подтверждении persisted SDK события
и отсутствии более нового отказа Claude. Сохранить прежнее значение и SQLite backup.
Не удалять произвольные cooldown и не считать quota=null подтверждённым allowed.

Проверки и результаты production приёмки записаны в PR и тикете #48; настоящая модель
не вызывается для проверки маршрутизации. Регрессии покрывают абсолютный reset, повтор,
expiry, restart, старый allowed, новые отказы и сохранение срока при terminal error.
