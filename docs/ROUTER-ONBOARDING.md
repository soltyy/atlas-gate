# Добавление Router через Gate

Полный порядок подключения находится в пакете документации **Atlas Router**:
[ROUTER-ONBOARDING.md](https://github.com/soltyy/atlas-router/blob/codex/router-node-contract/docs/ROUTER-ONBOARDING.md).

Документ описывает установку на одной машине с Gate, удалённый HTTPS и исходящее
соединение за NAT, выбор организации и маршрутов, группы аккаунтов, регистрацию
и одобрение, готовность SDK и настройки ресурсов без исходного предела 4.

Изменения порядка подключения вносить в документ Router. Эта страница сохраняет
прежний адрес в документации Gate и ведёт к основному документу.

Конфигурация и размещение самого Gate: [DEPLOYMENT.md](DEPLOYMENT.md).
