# Atlas Gate 0.2.0 — SDK web/files

09.10.2026. Gate #34, Router #58. Поиск SDK и чтение оригиналов доступны новым
сессиям по умолчанию без дополнительных переключателей Gate. Возможности
определяются выбранным Router; ответ создания подтверждает точный набор.

Gate публикует возможности моделей в подписанном профиле, сохраняет negotiated
параметры и привязку node/session. Новые file/sdk-tools endpoints проксируются
через direct и connector. Проверки владения, idempotency и разрешённых маршрутов
сохранены. Отзыв SDK-разрешения блокирует новые действия, но позволяет остановить
ход и удалить свою сессию. В SDK-зависимости Gate не добавлены библиотеки провайдеров.

Контракт и задачи харнесам: [SDK-WEB-FILES.md](SDK-WEB-FILES.md).

## Приёмка и выпуск

- Полная suite с реальным сетевым Router на сценарном SDK, включая direct/connector,
  повтор загрузки, чужое устройство, отсутствие ACK и отзыв политики.
- Отдельный живой Gate → Router → Claude и Codex: регистрация тестового устройства,
  проверка подписи профиля, создание без sdkTools, чтение случайного Excel, native
  поиск и polling SDK-событий. Тестовые сессии закрываются.
- `uv build`, исходный ZIP из Git, wheel и SHA256SUMS — GitHub Release v0.2.0.
  Итоговые числа проверок указаны в выпуске. UI харнесов этим выпуском не обновляется.

## Развёртывание и откат

Сначала Router 0.8.0 с готовым файловым runtime, затем Gate. Сохранить предыдущие
ссылки, конфигурации и SQLite через backup API. Установить locked зависимости в
новом каталоге, дождаться активных ходов перед перезапуском. После переключения
проверить health, node identity, signed settings, ACK и загрузку/удаление оригинала.
Конфигурации организаций менять для включения функций не нужно. Существующие
привязки и параметры уже открытых сессий не подменяются.

Изменение SQLite аддитивное: router_bindings.sdk_tools сохраняет ожидаемый ACK для
reconcile неоднозначного создания. Старые записи совместимы. Откатить ссылки можно
после завершения активных ходов; не удалять originals и не восстанавливать backup
поверх живой БД. На старом Router новый контракт должен считаться недоступным.
