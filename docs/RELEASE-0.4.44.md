# Gate 0.4.44 — сверка исходных операций

Кандидат PR #148 исправляет отрицательную сверку непринятого prompt после
обновления Router, повтор неизвестного session-scoped Stop, гонку dispatch
и отказа при ответе на вопрос, а также потерю callback status/callId в Router409.
Исходные идентичности и байты результата сохраняются; инструменты ради
восстановления не выполняются повторно.

Новая проверка закрытого prompt требует Router capability
`closed_prompt_absence_v1`; сохранён прежний квалифицированный fallback 0.8.24.
Сам номер более новой версии не разрешает отрицательное доказательство.
Парный выпуск Router 0.8.32 — PR #131.

Маркер question-answer dispatch хранится отдельно от исходной таблицы:
сохранена совместимость её ten-value INSERT при откате. Неизвестный legacy
Stop не переотправляется. Первый запоздалый Stop по-прежнему session-scoped;
exact-turn capability этим выпуском не добавляется.

Полный paired CI обнаружил регрессию 0.4.43: после завершения хода сохранённая
нагрузка соседнего Router общего аккаунта мешала следующему допуску. Перед новым
prompt/compact теперь обновляется только ограниченный общий account_group,
вне SQLite lock. Неизвестная нагрузка отклоняет новый допуск до расхода квоты;
повтор старой записанной квитанции остаётся доступен. Другие аккаунты не опрашиваются.
Четыре auth fixture и один quota fixture перенесены на действующие границы
preflight; неоднозначный отказ отдельно обязан сохранять unknown и квоту до сверки.

Подробные воспроизведения, адресные проверки и независимый аудит:
[CONTRACT-AUDIT-20261119.md](CONTRACT-AUDIT-20261119.md).
Полная квалификация выпуска и факт установки фиксируются отдельно.
Harness дорабатывает его собственный агент; draft #576 — материалы анализа,
а не клиентский выпуск. Исходники поверхности 1С в этот аудит не входили.
