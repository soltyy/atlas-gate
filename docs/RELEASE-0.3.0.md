# Gate 0.3.0 — расход токенов и кеша

Исправляет отсутствие видимости расхода подписочных ходов (#39).
Новый защищённый отчёт `/harness/admin/usage` и вкладка «Расход» показывают
суммы по устройствам/моделям, чтение/запись кеша, выход, покрытие измерений,
длительность SDK и ID ходов. Неизвестные значения отличаются от нуля.

Поставляются wheel, sdist, исходный ZIP со встроенной собранной Vue админкой,
SHA256SUMS через GitHub Release v0.3.0. Полный контракт: [TOKEN-USAGE.md](TOKEN-USAGE.md).

БД: additive agent_usage_details + индекс usage_ts; старые строки не изменяются,
receipt/detail/usage атомарны. Старый Gate совместим с новой таблицей для отката.
Router и харнесы обновления для отображения отчёта не требуют.

Установка: подготовить отдельный release-каталог, SOURCE_REVISION, выполнить
uv sync --locked --no-dev, проверить отсутствие активных ходов, сделать
SQLite online backup и резервную копию конфигурации. Переключить только Gate
с проверкой health, discovery и админского usage. При отказе вернуть прежнюю
ссылку и Gate. Router не перезапускать, его PID проверить до/после.

Приёмка: полный Python/сетевой набор и UI test/build; живой авторизованный отчёт
с историческими и новыми SDK измерениями, повтор без двойного учёта,
доступность админки и отсутствие доступа с device token. Подписочные данные
не считаются денежной стоимостью. Исторические отсутствующие метрики неизвестны.

Свежая проверка: 102 Python tests PASS, 6 opt-in SKIP (131,62 с);
49 UI tests PASS; vue-tsc + Vite build; uv build wheel/sdist.
Браузер 1280×800: вкладка, карточки, таблицы и фильтры показаны,
переполнения страницы по горизонтали нет (протокольные данные).
