# Восстановление подписки (#69)

Сохранённый отказ SDK и resetsAt — наблюдение, а не запрет на новый запрос.
После изменения тарифа доступ может восстановиться раньше даты сброса.

При выборе новой сессии Gate предпочитает совместимый узел без старого cooldown,
но при отсутствии такого узла пропускает запрос к SDK. Resume сохраняет прежний
узел. Prompt и compact также не блокируются по исторической квоте. Авторизация,
drain, реальная конкуррентность и журнал идемпотентности продолжают действовать.

Gate не повторяет автоматически старый ход и не переводит историю на другую
подписку. Реальный новый отказ Router/SDK сохраняется в квитанции. Повтор того же
ключа возвращает ту же квитанцию; новая попытка использует новый логический ключ.
Исторические quota/cooldown остаются в диагностике до нового события или сброса;
их наличие больше не препятствует проверке восстановленного доступа.
