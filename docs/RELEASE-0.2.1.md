# Atlas Gate 0.2.1 — восстановление доступной подписки

09.10.2026. Gate #37; блокер Harness #232 и создания сессий EDT.

После подтверждённого Router события `rate_limit` со статусом `allowed` или
`allowed_warning` Gate удаляет cooldown соответствующей группы аккаунта из
памяти и SQLite. Ранее он возвращался без очистки: свободный Codex исключался
из выбора с ошибкой `capacity_exceeded` до обращения к SDK. Перезапуск Gate
снова поднимал устаревшую блокировку из БД.

Обновление `/v1/node` проходит проверку идентичности Router до обработки квоты.
Пустые/неизвестные данные не означают восстановление; другие группы аккаунтов,
политики организации и настоящие отказы провайдера остаются в силе.

Регрессии проверяют оба разрешающих статуса, повтор события, общую группу
нескольких узлов, чужую группу, restart, создание сессии и новый ход после
отказа. Итог полной сетевой suite и живой проверки публикуется в GitHub Release.

Поставка: `uv build`, source ZIP и wheel; Gate обновляется отдельно от Router.
Перед переключением сохранить SQLite backup и прежнюю ссылку, дождаться
завершения ходов. Миграции схемы и ручного удаления cooldown не требуется:
штатный свежий probe снимает восстановленную блокировку. Откат — прежняя
ссылка Gate; восстановление БД поверх живой службы не требуется.
