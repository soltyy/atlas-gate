# Работа с Atlas Gate

Рабочий язык — русский. Перед работой читать `docs/CLAUDE-HANDOFF.md`.

- Самостоятельный Gate; не импортировать atlas_router или библиотеки Claude/Codex SDK.
- Router вызывается только через сетевой контракт. Совместная установка на одной машине обязательна.
- Новая сессия выбирает узел; существующая всегда использует постоянную привязку в SQLite.
- Владелец, организация, узел и локальная сессия проверяются до каждого делегирования.
- Тесты — временные БД/ключи и свободные порты. Работающий AtlasRouter не перезапускать для разработки.
- Ключи, profiles, nodes.json, SDK credentials и журналы не добавлять в Git.
- Состояние issues/PR перечитывать перед изменением. Регламент: `docs/ISSUES.md`.
- Начальные ограничения и незавершённые этапы обозначать явно; документация не доказывает реализацию.
